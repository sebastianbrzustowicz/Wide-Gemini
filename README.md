# Wide-Gemini

Extension for Gemini extension. It is possible to adjust the width with a slider.   
Additionally, you can enable "Clean View" to hide extra page elements for a cleaner interface.
The extension also includes numerous quality-of-life improvements, such as a sticky position for the copy button, the ability to copy tables in various formats, and much more.
