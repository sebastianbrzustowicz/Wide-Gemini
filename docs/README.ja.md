# ワイド・ジェミニ (Wide-Gemini)

Gemini用の拡張機能です。スライダーを使って画面の幅を調整することができます。
さらに、「クリーンビュー (Clean View)」を有効にすることで、余計なページ要素を非表示にしてインターフェースをすっきりとさせることができます。
また、この拡張機能には、コピーボタンの固定配置（sticky position）や、様々なフォーマットでのテーブルコピー機能など、快適性を向上させる数多くの改善が含まれています。
