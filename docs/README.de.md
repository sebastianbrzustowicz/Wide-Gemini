# Breites Gemini (Wide-Gemini)

Erweiterung für die Gemini-Erweiterung. Es ist möglich, die Breite mit einem Schieberegler anzupassen.   
Zusätzlich können Sie die „Bereinigte Ansicht“ (Clean View) aktivieren, um zusätzliche Seitenelemente für eine übersichtlichere Benutzeroberfläche auszublenden.
Die Erweiterung enthält außerdem zahlreiche Verbesserungen der Benutzerfreundlichkeit (Quality-of-Life Improvements), wie z. B. eine fixierte Position (Sticky Position) für die Kopierschaltfläche, die Möglichkeit, Tabellen in verschiedenen Formaten zu kopieren, und vieles mehr.
