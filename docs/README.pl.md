# Szeroki-Gemini (Wide-Gemini)

Rozszerzenie do dodatku Gemini. Istnieje możliwość dostosowania szerokości za pomocą suwaka.   
Dodatkowo możesz włączyć "Czysty Widok" (Clean View), aby ukryć zbędne elementy strony dla uzyskania bardziej przejrzystego interfejsu.
Rozszerzenie zawiera również wiele usprawnień ułatwiających korzystanie, takich jak przyklejona pozycja (sticky position) dla przycisku kopiowania, możliwość kopiowania tabel w różnych formatach i wiele więcej.
