# 와이드 제미나이 (Wide-Gemini)

제미나이 확장 프로그램을 위한 확장 기능입니다. 슬라이더를 통해 화면 너비를 조절할 수 있습니다.
또한, 더 깔끔한 인터페이스를 위해 페이지의 불필요한 요소를 숨기는 "클린 뷰 (Clean View)" 기능을 활성화할 수 있습니다.
본 확장 프로그램은 복사 버튼 고정 위치(sticky position) 지정, 다양한 형식의 표 복사 기능 등 사용 편의성을 높여주는 수많은 개선 사항을 포함하고 있습니다.
