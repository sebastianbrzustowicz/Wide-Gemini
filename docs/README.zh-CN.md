# 宽屏双子座 (Wide-Gemini)

这是针对 Gemini 扩展程序的增强扩展。可以通过滑块自由调节界面宽度。
此外，你还可以启用“清爽视图”（Clean View）来隐藏页面上的多余元素，获得更简洁的界面。
该扩展还包含了许多提升使用体验的优化，例如固定（sticky）位置的复制按钮、支持以多种格式复制表格等等。
