# Широкий Джемини (Wide-Gemini)

Расширение для интерфейса Gemini. Позволяет настраивать ширину экрана с помощью ползунка.  
Дополнительно вы можете включить функцию «Чистый вид» (Clean View), чтобы скрыть лишние элементы страницы для более минималистичного интерфейса.  
Расширение также включает множество улучшений для удобства использования, таких как фиксированное положение (sticky position) для кнопки копирования, возможность копирования таблиц в различных форматах и многое другое.
