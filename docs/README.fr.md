# Gemini-Large (Wide-Gemini)

Extension pour l'extension Gemini. Il est possible d'ajuster la largeur à l'aide d'un curseur.   
De plus, vous pouvez activer la "Vue épurée" ("Clean View") pour masquer les éléments superflus de la page afin d'obtenir une interface plus propre.
L'extension comprend également de nombreuses améliorations de la qualité de vie, telles qu'une position fixe (sticky) pour le bouton de copie, la possibilité de copier des tableaux dans différents formats, et bien plus encore.
