# Gemini-Ancho (Wide-Gemini)

Extensión para la extensión de Gemini. Es posible ajustar el ancho con un control deslizante.   
Además, puedes activar la "Vista Limpia" (Clean View) para ocultar los elementos adicionales de la página y obtener una interfaz más despejada.
La extensión también incluye numerosas mejoras de calidad de vida, como una posición fija (sticky position) para el botón de copiar, la capacidad de copiar tablas en varios formatos y mucho más.
